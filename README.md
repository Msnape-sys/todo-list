# Get It Together

Get It Together is a simple to-do list app I built to practice using JavaScript to make a webpage interactive.

A simple web-based task tracker that allows users to write down what needs to get done and tackle it one task at a time.

## About the Project

I built this project while learning how JavaScript can interact with HTML elements on a webpage.

The user can type a task into the input field and add it to their task list. The project helped me practice taking information from a user and using JavaScript to update what they see on the page.

## Built With

- HTML
- CSS
- JavaScript

## What I Practiced

While building this project, I practiced:

- DOM manipulation
- Event listeners
- Functions
- Working with user input
- Creating and updating HTML elements with JavaScript
- Connecting HTML, CSS, and JavaScript
- Building interactive features based on user actions

## What I Learned

This project helped me better understand the relationship between HTML and JavaScript.

Instead of creating a webpage that only displays information, I was able to make the page respond to what the user does.

It also gave me more practice breaking a feature into smaller steps, like getting the user's input, responding to a button click, and updating the task list.

## Future Improvements

Some things I could add in the future:

- Save tasks so they remain after refreshing the page
- Add due dates
- Allow users to edit tasks
- Organize tasks by priority
- Improve accessibility
- Add filters for completed and unfinished tasks
